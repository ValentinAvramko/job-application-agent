## Цель

`ingest-vacancy` корректно пишет строки в обновленный `response-monitoring.xlsx`, где после `Активна` добавлена колонка `Обновлена`, заполняет ее датой публикации или обновления вакансии из источника и по умолчанию ставит `Письмо = Да`.

## Контекст

Код инструмента находится в `./tooling/application-agent`. Текущая реализация записи Excel использует старую карту колонок `A:K`, где `E` была `Компания`, а `K` была датой отклика. В корневом `response-monitoring.xlsx` фактическая карта теперь `A:Q`: `E=Обновлена`, `F=Компания`, `G=Позиция`, `H=Страна`, `I=Режим работы`, `J=Способ`, `K=Письмо`, `L=Отклик`.

Текущий корневой workbook уже изменен пользователем. Найдено 70 активных строк (`Активна = Да`) с пустой `Обновлена`: 69 `hh.ru` и 1 `jobs.ashbyhq.com`.

## Границы

### Входит в scope

- Обновить source/enrichment модель для даты публикации/обновления вакансии.
- Обновить запись в `response-monitoring.xlsx` под новую карту колонок.
- Для новых ingest-строк писать `Письмо = Да`.
- Добавить внутренние helpers для backfill `Обновлена`.
- Обновить тесты и выполнить одноразовый backfill текущего workbook.

### Не входит в scope

- Добавление нового публичного CLI для backfill.
- Миграция существующих значений `Письмо`.
- NLP-извлечение дат из произвольного текста вакансии.

## Допущения

- Для HH используется `published_at`.
- Для generic `JobPosting` используется `dateModified`, иначе `datePosted`.
- Если дата из источника не извлечена, `Обновлена` остается пустой.
- Backfill меняет только колонку `E`.

## Риски и неизвестные

- Live-доступ к источникам может быть ограничен сетью или политиками сайтов.
- У одной активной строки источник не HH; дата будет заполнена только если в странице есть структурированные данные.
- Низкоуровневая запись XLSX должна сохранить существующие стили и колонки до `Q`.

## Внешние точки касания

- `response-monitoring.xlsx` - чтение / обновление / проверка - backfill колонки `Обновлена` для активных строк.
